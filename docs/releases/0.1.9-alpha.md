# RecNote 0.1.9-alpha

- 拍照仅调用手机自带相机，移除应用内置相机；全尺寸原图、横屏方向和录音时间关联保留。
- 日程功能、日程自动录音、网盘同步提供独立开关；关闭后保留已有配置。
- 本地模型支持查看占用和安全删除；新增 SenseVoice Small INT8 与 Whisper Tiny INT8。
- 列表和详情显示“已整理 / 未整理”，并区分排队、整理中、暂停、失败及原稿变化。
- 整理任务独立于页面，在后台和锁屏时继续；中断后自动恢复，支持暂停。已保存结果复用，输出过长时自动拆小未完成批次，修复 DeepSeek 输出截断后反复继续仍失败的问题。
- 支持直接保存 PDF，打包导出包含 PDF、Markdown 和相关照片。整理或编辑完成后，三者自动上传同一网盘目录；导入音频只生成文字 Markdown/PDF。
- PDF 生成和网盘上传也有持久任务；失败不影响本地已完成笔记。升级保留已有课堂、模型配置和自定义系统提示词。

版本名 0.1.9-alpha，versionCode 8，Room 6。APK 沿用固定签名。编译、单测、lint 和仪器测试源码编译属于工程验证；实际手机相机、锁屏后台稳定性、PDF 排版与真实网盘仍按 OpenSpec 人工清单验收。系统强制停止期间不能运行，再次打开后自动恢复待整理任务。
