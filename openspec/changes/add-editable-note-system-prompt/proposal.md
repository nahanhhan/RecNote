# Proposal

## Why

笔记整理目前固定发送代码里的系统提示词，用户无法改变整理风格、详细程度或组织方式。将提示词编辑能力放到设置中，允许用户用变量引用日期时间与录音标题，并继续使用应用现有的结构化笔记保存流程。

## What Changes

- 设置「云端笔记整理」区域增加「系统提示词」按钮，打开独立编辑页，可编辑、保存、恢复默认、插入变量与预览展开结果。配置为应用级，所有供应商及预设共用；不影响接口测试通过状态。
- `{{datetime}}` 替换为整理任务开始时的系统短日期与时间，遵循当前语言区域、12/24 小时制和时区；`{{title}}` 使用该录音绑定的原始 ICS 日程名，未绑定时使用用户输入的标题。其他变量暂不展开，保留原文。
- 每个新整理任务冻结展开后的系统提示词，全部批次与中断续跑复用它；修改设置只影响新任务。数据库升到 4，仅追加任务提示词列，旧任务使用原有提示词继续，保留原始记录和笔记。
- 原有提示词保留为默认值，新增日期时间/标题变量。工具说明移除重复的写作风格限制，用户编辑的系统提示词完整发送；结构、来源编号校验和本地保存规则继续由应用执行。
- Debug 请求日志省略系统提示词正文。连接能力测试继续使用固定合成测试要求，不发送用户模板或真实录音资料。
- 同步用户文档、架构、示例工具定义与验证清单。版本更新到 `0.1.8-alpha` / code 7，正常上传并发布对应 APK，保留历史版本。

## Capabilities

### New Capabilities

- `note-system-prompt`: 应用级提示词编辑、默认恢复、变量替换、任务快照和旧任务兼容。

### Modified Capabilities

（无。现有正式规格未定义笔记提示词配置能力。）

## Impact

涉及 `core` 的模板替换与请求构造，设置存储、提示词编辑页、设置导航、整理任务创建及 Room 3→4 迁移、调试日志和工具定义。无需新增依赖。录音、ICS 导入、WebDAV 上传及导入音频的仅文字限制保持原有行为。

不包括模板预设库、每个供应商单独提示词、任意变量脚本执行、提示词云同步或修改既有笔记格式。
