# Spec Delta

## MODIFIED Requirements

### Requirement: 完整笔记自动上传

手机使用本地或远程 ASR 原稿整理成功，或用户保存编辑笔记后，若笔记同步已启用，系统 SHALL 排队上传完整 Markdown 及其本地照片快照。导入音频 MUST 仅上传文字笔记。旧笔记 SHALL 支持详情页手动上传。照片 MUST 先于 Markdown 上传并保持相对链接；笔记同步任务 MUST NOT 上传音频、模型或 API 密钥。用户显式选择远程模式的原始音频 SHALL 只通过独立的远程音频中转任务与目录传送，不属于笔记同步，不得混入笔记文件包。

#### Scenario: 自动上传图文笔记

- **WHEN** 用户完成一份带本地照片的笔记整理且已保存网盘地址
- **THEN** 自动上传笔记和照片，网盘中的 Markdown 可正常引用照片

#### Scenario: 导入音频

- **WHEN** 导入音频完成文字整理
- **THEN** 只排队文字笔记，不追加照片、录音或图文整理

#### Scenario: 远程原稿在手机整理

- **WHEN** 用户取回远程 ASR 原稿并在手机完成既有 LLM 整理，且已开启笔记同步
- **THEN** 生成既有笔记同步任务，只有笔记和其引用的本地照片，重复检查 ASR 结果不会触发笔记上传

## ADDED Requirements

### Requirement: 安全展示连接测试失败原因

WebDAV 测试 SHALL 显示失败阶段（检查目录、写入测试文件、清理测试文件），并区分连接被拒绝、超时、DNS、HTTPS 握手、证书和系统网络限制。Info/Debug 日志 SHALL 记录测试开始、成功／失败、阶段、固定分类与状态码，MUST NOT 记录地址、文件夹名、账号、原始异常消息或服务端正文。暂时网络失败 SHALL 保留既有有限重试；证书和系统权限错误 MUST NOT 自动重试，MUST NOT 自动降级 HTTPS 或关闭证书校验。

#### Scenario: 手机本机服务未监听
- **WHEN** 手机的 OpenList 目标端口拒绝连接
- **THEN** 测试显示连接被拒绝及检查服务、地址和端口的提示，导出日志包含检查阶段及 REFUSED 分类，不包含真实地址或凭据

#### Scenario: 账号无效或文件夹权限不足
- **WHEN** WebDAV 返回 401 或 403
- **THEN** 手机保留原有账号／权限提示，并附失败阶段与安全状态码记录，不把它们误报为证书问题
