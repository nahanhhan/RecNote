# 设计

## 整理与恢复

保留用户发起整理的语义，不把录音结束变成自动发起整理。将任务在数据库保存后交给持久队列执行，独立于页面生命周期。用户发起时允许前台服务立即运行，后台恢复由系统调度；任务持有局部唤醒锁并显示进度通知，锁屏不取消。任务串行，避免同一批次重复保存。暂停、永久错误和原稿变化停止自动循环；暂时网络错误有限退避，配置修复后支持手动继续。

创建任务使用较小的输入批次；对旧任务或再次截断的未保存批次按文本/图片拆成两个，保持原资料、时间、图片索引及任务冻结的提示词。拆分计划在下一次请求之前持久保存；保存成功的批次不拆分或重发。无法继续拆分则停止并显示输出超限原因，不把残缺 JSON 当成功。工具调用仅在完整结构和来源校验通过后接受，确认消息兼容空工具数组。

## 原生相机

后台实现采用每任务唯一 WorkManager 工作、进程内串行锁、dataSync 持续通知和每批有界唤醒锁。Android 16 的任务配额及系统强制停止仍遵守系统调度，不承诺绕过省电限制；再次进入应用恢复待执行工作。DeepSeek flash/v4 明确设置 32768 输出 token，其余模型不发送未经确认的超限参数，并统一使用截断拆分兜底。

使用系统拍照入口及 FileProvider 全尺寸文件。录音采样时钟是照片关联依据；启动时保存采样时间和墙上时间，返回时优先读取照片 EXIF 拍摄时间在本次相机打开期间的有效值，按录音增量换算，暂停期间不增长。临时拍照记录持久化，旋转/进程重建不丢关联，取消删除临时文件。照片成功落库才增加原稿版本。移除内置 CameraX 相机及依赖，不要求应用自己的相机权限；没有系统相机时提示用户检查手机相机应用。导入音频不出现相机入口。

## 开关与模型

开关持久化，旧用户保留既有日程和已配置网盘行为。日程关闭停止后台刷新和新录音匹配；自动开录可独立关闭。网盘关闭撤销待发送任务且保留地址/加密凭据，不把旧任务发往新配置。模型删除与录音/导入/下载互斥，清理安装目录和续传文件，校验目录边界；记录继续保留，模型可重新下载。

## PDF 和同步

PDF 必须可由应用上下文自动生成，不依赖用户打开系统打印页面。使用 Android PDF 画布分页排版中文、标题、列表、表格和本地照片；公式使用离线 KaTeX 渲染后嵌入，等待资源就绪，失败明确报告，不能上传缺页/空白 PDF。导出和同步使用同一个资料快照；PDF 生成失败只影响导出/上传，不回滚已完成笔记。快照中照片与 PDF 先上传，Markdown 最后作为完成文件；旧队列仍能恢复原格式，新快照强制包含 PDF。用户编辑产生新版本路径。

## 验证

核心单元测试覆盖截断识别、资料无损拆分、状态、恢复策略；模拟接口覆盖拒绝/网络/参数错误；仪器测试源码覆盖任务恢复、模型删除、原生回传与 PDF 本地生成。CI 编译测试、lint 和 APK。真机后台/锁屏/OEM 相机、中文 PDF/公式、多语言识别和真实 WebDAV 单独人工验收。
