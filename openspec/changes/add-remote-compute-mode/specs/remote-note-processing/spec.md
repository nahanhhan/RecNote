# Spec Delta

## Purpose

让完整远程 ASR 原稿进入 RecNote 已有的手机笔记整理流程，由用户使用手机保存的供应商配置、提示词和照片设置主动提交模型，保留现有来源校验、任务恢复、编辑及导出能力，并保持电脑只负责音频识别的边界。

## ADDED Requirements

### Requirement: 手机手动控制提交 LLM

远程录音详情 SHALL 保留「整理笔记」入口。只有录音已停止且全部原稿已取回验证时才可进入既有手机整理流程，并沿用现有资料可整理性检查。点击该入口 SHALL 在手机创建现有整理任务并直接调用配置的云端供应商，MUST NOT 向电脑发送整理请求。录音结束、电脑 ASR 完成、进入详情、刷新或应用重启 MUST NOT 自动创建新的 LLM 整理任务；既有用户已提交任务的恢复规则 SHALL 保持。

#### Scenario: 识别完成后等待用户
- **WHEN** 手机确认所有原稿完成但用户未点击整理
- **THEN** 仅显示原稿与可用按钮，不发出 LLM 整理请求

#### Scenario: 用户发起整理
- **WHEN** 用户在完整原稿状态点击「整理笔记」
- **THEN** 手机按现有规则保存来源快照并调用手机配置的供应商，界面显示整理中，电脑没有整理请求

### Requirement: 整理沿用手机配置与来源快照

两种 ASR 模式 SHALL 使用相同的手机供应商预设、模型、API Key、系统提示词、变量与连接测试规则。手机 SHALL 按既有流程将当前原稿、来源版本及照片选择保存为本地任务快照；用户编辑后的原稿 SHALL 进入新整理任务，提示词冻结和旧任务恢复 SHALL 沿用现有约定。电脑服务 `config.yaml` MUST NOT 包含 LLM 配置，电脑不得获取手机 LLM Key、提示词或整理输入快照。

#### Scenario: 编辑原稿后整理
- **WHEN** 用户修改远程原稿并发起整理
- **THEN** 手机现有整理流程使用修改后的原稿，不重新从电脑原稿覆盖用户编辑

#### Scenario: 手机提示词快照
- **WHEN** 整理任务已开始后用户修改手机提示词，再继续旧任务
- **THEN** 旧任务使用原手机提示词快照，新任务才使用新模板，与 ASR 模式无关

### Requirement: 笔记沿用手机保存与导出流程

使用远程 ASR 原稿生成的笔记 SHALL 按现有手机工具调用、结构／来源校验、事务与批次回执流程保存。完成后的阅读、编辑、PDF／Markdown 导出及 WebDAV 笔记同步 SHALL 沿用原流程。电脑 MUST NOT 生成笔记或发布笔记结果目录，手机不得把 ASR 原稿 Markdown 当作已整理笔记，也不新增电脑笔记回收格式。

#### Scenario: 手机整理完成
- **WHEN** 手机配置的供应商按现有协议完成笔记提交和保存确认
- **THEN** 笔记保存到原录音，可离线阅读、编辑、导出及按原设置同步

#### Scenario: ASR 原稿不是笔记
- **WHEN** 手机仅取回 `.transcripts/` 原稿而用户未发起手机整理
- **THEN** 仅标记原稿完成，不生成笔记完成状态或触发笔记同步

### Requirement: 照片沿用手机既有整理设置

电脑 ASR 任务 MUST 只处理音频，不接收手机照片。麦克风记录 SHALL 继续支持拍照；手机 LLM 的读图开关、模型能力测试、照片选择与不读图时的时间关联插图 SHALL 保持现有行为，不因远程识别模式而强制关闭或改为固定照片附录。导入记录 MUST 继续只整理文字。

#### Scenario: 拍照后整理
- **WHEN** 用户在远程麦克风录音中拍照并生成文字笔记
- **THEN** 电脑只识别音频，手机按既有读图设置处理选中照片，笔记导出和同步使用原有照片关联规则

#### Scenario: 导入音频
- **WHEN** 手机使用远程识别的导入音频原稿完成整理
- **THEN** 笔记、导出及笔记同步均只含文字，无拍照或读图流程

### Requirement: 手机 LLM 与电脑 ASR 生命周期独立

手机 LLM 与电脑 ASR SHALL 使用独立的配置、连接测试与任务状态。ASR 后端下线、ASR token 改变或全局识别模式切换 MUST NOT 改变已取回原稿、已经创建的手机整理任务或手机供应商测试状态。手机 LLM 的失败重试、暂停和恢复 SHALL 沿用现有流程，并保留原稿与已保存笔记；用户未修改手机整理设置时不得要求因 ASR 设置变化重新配置 LLM。

#### Scenario: 电脑下线后手机整理
- **WHEN** 手机已取回全部原稿，之后电脑 ASR 服务关闭
- **THEN** 仍可直接使用手机配置的供应商整理，无需电脑在线

#### Scenario: 整理失败
- **WHEN** 手机供应商拒绝、模型输出无效或整理中断
- **THEN** 显示可读原因并允许重试，原稿和已有笔记保持
