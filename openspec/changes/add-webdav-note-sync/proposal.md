# Proposal

## Why

v2 已通过 ICS 日程关联录音，但整理后的笔记仍需手动导出。增加 WebDAV 上传，让笔记生成后自动保存到用户网盘，并按 **ICS 日程名**归档。

## What Changes

- 设置新增「WebDAV 云同步」：地址占位提示 `http://127.0.0.1:5244/dav`，实际默认空；非空并保存即启用，留空关闭。支持账号、密码、连接读写测试，凭据本机加密保存。
- 新增独立二级页面维护「ICS 日程名 → WebDAV 根目录内文件夹」映射，支持增改删；按录音保存的原始 `scheduleTitle` 精确匹配，未绑定日程或未匹配映射时使用根目录。
- 整理成功、保存笔记编辑后自动排队上传 Markdown 和笔记使用的本地照片；历史笔记可在详情页手动上传。导入音频保持仅文字流程。
- 持久化上传快照和状态；显示等待、上传、成功或失败；网络错误自动有限重试，详情页可手动重试。上传失败不影响本地笔记和整理结果。
- 每份笔记使用独立文件夹，内容变化保存为新版本；重复上传同一快照使用同一路径。删除本地记录清除待上传任务，不删除云端文件。
- 为用户配置的 HTTP WebDAV 允许明文连接；模型接口与 ICS 订阅仍强制 HTTPS，模型下载禁止 HTTPS 跳转到 HTTP。Debug 也不记录新增 WebDAV 凭据。
- 用户文档、架构说明、验证与状态记录随本 change 更新；版本更新到 `0.1.7-alpha` / code 6，通过验证后发布同版本 APK。
- 补齐尚未发布 APK 的 `0.1.6-alpha` 历史版本，标签指向原始 `c8d992a` 提交，独立构建；不将旧源码或旧包覆盖当前版本。

## Capabilities

### New Capabilities

- `webdav-note-sync`: WebDAV 配置、连接测试、笔记与照片上传、持久化恢复、失败重试与状态反馈。
- `schedule-folder-routing`: ICS 日程名与网盘根目录内路径的管理和归档规则。

### Modified Capabilities

（无。ICS 的 HTTPS 订阅与录音行为保持其既有要求；本 change 明确新增网络边界。）

## Impact

涉及 `core` 的路径/快照与上传状态逻辑；`app` 的设置存储、WebDAV 客户端、WorkManager 上传任务、笔记完成入口、详情页、设置二级导航与删除清理；无需数据库升级。复用现有 OkHttp、WorkManager、AndroidKeyStore，无新增第三方依赖。验证使用合成资料和本机模拟服务，不使用真实账号或真实笔记。

不包括双向同步、下载恢复、远端删除、网盘账号 OAuth、自动上传录音、PDF 自动生成、同步 API 密钥或导入音频的图文整理。
