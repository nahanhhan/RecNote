# RecNote 0.1.7-alpha

- 设置新增 WebDAV 云同步、加密账号密码和连接读写测试。
- 完整笔记生成及编辑保存后自动上传 Markdown 与其本地照片，详情页显示状态并支持手动上传或失败重试。
- 新增日程文件夹管理页，按原始 **ICS 日程名**归档；未匹配和导入音频笔记保存到根目录。
- 上传任务可在网络恢复与进程重启后继续；内容变化保留新版本；本地删除不删除网盘副本。
- 地址实际默认空；`127.0.0.1` 示例指手机自身，电脑网盘需填写电脑地址。支持 HTTP，建议 HTTPS；模型和日程接口仍保持 HTTPS。

版本名 `0.1.7-alpha`，versionCode 6，优化 APK 使用仓库固定签名。GitHub 编译、测试与 lint 属工程验证；真实网盘连接、手机后台与图文打开仍按 OpenSpec 的人工验收清单确认。
