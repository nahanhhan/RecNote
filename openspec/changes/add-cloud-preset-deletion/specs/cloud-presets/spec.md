# Spec Delta

## Purpose

定义云端笔记整理配置预设的管理边界：用户可删除不再需要的预设及其配置数据，系统保证始终至少保留一个预设，并在删除激活预设后回落到可用预设。

## ADDED Requirements

### Requirement: 删除预设入口与确认

设置-云端笔记整理 SHALL 提供「删除预设」入口，与「新增预设」「重命名预设」并列，作用于当前选中的预设。执行删除前 MUST 弹出显示预设名称的确认对话框，仅确认后才删除；取消 MUST 不产生任何改动。存在进行中的云端操作时该入口 MUST 禁用。

#### Scenario: 确认删除

- **WHEN** 用户在预设多于一个时点击「删除预设」，并在确认对话框中确认
- **THEN** 该预设从预设列表移除，对话框关闭，界面提示已删除该预设

#### Scenario: 取消删除

- **WHEN** 用户在删除确认对话框中选择取消
- **THEN** 预设列表与所有配置数据保持不变

### Requirement: 至少保留一个预设

预设列表 MUST 始终保留至少一个预设。仅剩一个预设时「删除预设」入口 MUST 禁用；删除请求对最后一个预设 MUST 拒绝执行并提示「至少保留一个预设」，且不产生任何改动。

#### Scenario: 仅剩一个预设时不可删除

- **WHEN** 预设列表只剩一个预设
- **THEN** 「删除预设」入口不可操作，且删除请求被拒绝，预设列表与配置保持不变

### Requirement: 删除后的激活预设回落

删除非激活预设 MUST NOT 改变当前激活预设。删除当前激活预设后，系统 MUST 将剩余列表中的第一个预设设为激活预设，界面 MUST 显示该预设保存的配置；被删除预设的未保存草稿 MUST NOT 出现在新激活的预设上。

#### Scenario: 删除非激活预设

- **WHEN** 当前激活「预设一」，用户删除「预设二」
- **THEN** 激活预设仍为「预设一」，其配置与测试状态不变

#### Scenario: 删除激活预设后回落

- **WHEN** 「预设一」「预设二」两个预设中当前激活「预设二」，用户删除「预设二」
- **THEN** 激活预设变为「预设一」，界面显示「预设一」保存的配置，而非「预设二」的草稿

### Requirement: 删除连带清除预设数据

删除预设 MUST 同时清除该预设保存的全部云端配置与连接测试状态（API 地址、模型名称、密钥、严格模式、图片开关、测试标记）；其余预设及旧版共享供应商配置 MUST NOT 受影响。删除后新增的预设 MUST NOT 继承被删除预设的任何配置。

#### Scenario: 删除后无残留

- **WHEN** 用户删除一个已保存密钥且已通过测试的预设
- **THEN** 该预设的全部配置与测试标记被清除，其余预设的配置与测试状态保持原样

#### Scenario: 重新新增不继承旧配置

- **WHEN** 删除某预设后用户新增预设
- **THEN** 新预设为默认空白配置，不包含被删除预设的密钥、模型或测试状态
