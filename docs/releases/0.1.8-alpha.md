# RecNote 0.1.8-alpha

- 设置新增「系统提示词」按钮，进入后可编辑、保存、恢复默认、插入变量和预览；适用于全部模型配置预设的新任务。
- `{{datetime}}` 使用手机系统日期时间格式、12/24 小时制和时区；`{{title}}` 优先取这条录音绑定的原始 ICS 日程名，未绑定时用录音标题。
- 整理任务保存提示词快照，分批及中断恢复保持一致；升级前的任务继续使用原始提示词，已有录音与笔记保留。
- 工具说明移除重复的固定写作风格限制；输出仍按应用笔记结构和来源要求校验保存。
- Debug 请求日志省略系统提示词正文；连接能力测试不发送用户自定义模板。

版本名 `0.1.8-alpha`，versionCode 7，优化 APK 沿用仓库固定签名。GitHub 编译、单测、lint 和仪器测试源码编译属于工程验证；手机编辑体验、系统时间格式与真实模型效果仍按 OpenSpec 人工清单验收。
