# Spec Delta

## ADDED Requirements

### Requirement: 预设管理图标入口

「新增预设」「重命名预设」「删除预设」三个预设管理入口 SHALL 各自由一个图标按钮呈现，与「配置预设」选择器位于同一行，选择器占据行内剩余宽度。每个图标按钮 MUST 提供与入口含义一致的中文无障碍描述。存在进行中的云端操作时三个入口 MUST 均禁用；仅剩一个预设时「删除预设」入口 MUST 禁用。

#### Scenario: 三个入口与选择器同行

- **WHEN** 用户进入设置-云端笔记整理界面
- **THEN** 「配置预设」选择器右侧同一行呈现新增、重命名、删除三个图标按钮，三个入口不再以文字按钮单独占行

#### Scenario: 图标按钮的无障碍描述

- **WHEN** 辅助功能聚焦任一预设管理图标按钮
- **THEN** 该按钮播报与入口含义一致的中文描述（「新增预设」「重命名预设」或「删除预设」）

#### Scenario: 进行中的云端操作时全部禁用

- **WHEN** 存在进行中的云端操作（如读取模型列表或测试连接）
- **THEN** 三个预设管理图标按钮均不可操作

#### Scenario: 仅剩一个预设时删除禁用

- **WHEN** 预设列表仅剩一个预设且无进行中的云端操作
- **THEN** 「删除预设」图标按钮不可操作，「新增预设」「重命名预设」图标按钮可操作

## MODIFIED Requirements

### Requirement: 删除预设入口与确认

设置-云端笔记整理 SHALL 提供「删除预设」入口，与「新增预设」「重命名预设」并列，作用于当前选中的预设；三个入口 SHALL 以图标按钮呈现并与「配置预设」选择器位于同一行。执行删除前 MUST 弹出显示预设名称的确认对话框，仅确认后才删除；取消 MUST 不产生任何改动。存在进行中的云端操作时该入口 MUST 禁用。

#### Scenario: 确认删除

- **WHEN** 用户在预设多于一个时点击「删除预设」，并在确认对话框中确认
- **THEN** 该预设从预设列表移除，对话框关闭，界面提示已删除该预设

#### Scenario: 取消删除

- **WHEN** 用户在删除确认对话框中选择取消
- **THEN** 预设列表与所有配置数据保持不变
