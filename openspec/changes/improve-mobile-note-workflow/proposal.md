# 完善手机拍照、后台整理和完整笔记导出

## Why

用户日志中五次整理响应均以 `finish_reason=length` 结束，输出达到 8192 tokens，工具参数不是完整 JSON。旧任务反复发送相同批次，因此继续也失败；现有服务缺少持久自动恢复和锁屏保活。用户还需要原生相机、可关闭的日程/网盘功能、本地模型删除与更多选择、清晰的整理状态，以及自动同步 PDF。

## What Changes

- 持久排队整理，离开页面及锁屏继续；进程重启自动恢复，暂停入口保留用户控制。已保存批次复用；输出截断时持久拆分剩余批次，拒绝保存截断参数。
- 仅调用手机原生相机，移除内置相机；返回后按拍摄时间关联录音，并正确读取横屏 EXIF。
- 设置提供日程、自动开录、网盘同步独立开关，关闭不丢配置。
- 支持直接 PDF 导出及 PDF/Markdown/照片打包；整理或编辑成功后将三者的同一快照自动同步到同一网盘目录。导入音频只有文字 Markdown/PDF。
- 本地模型显示体积与说明，支持安全删除，并添加经核实的轻量/多语言模型。
- 列表与详情显示未整理/已整理及排队、整理中、暂停、失败、原稿变化状态。

## Capabilities

### New Capabilities

- `note-processing`: 整理队列、断点恢复、截断拆分、状态与暂停。
- `native-camera`: 原生相机拍照和时间关联。
- `note-export`: 自动生成 PDF 与完整导出包。
- `model-management`: 本地模型选择和安全删除。
- `personalization`: 日程与网盘开关。

### Modified Capabilities

- `webdav-note-sync`: 独立同步开关，以及 PDF/Markdown/照片快照同步。

## Impact

Android 后台服务/WorkManager、Room 迁移、工具协议和批次规划、设置/列表/详情、相机回传、PDF 排版、模型目录与下载校验、WebDAV 快照。系统提示词仍按既有规则冻结，不修改用户模板。工程验收由 CI 承担，真机和真实网盘验收单独记录。
